Quick Start — Unity Integration

Add DLC protection to your Unity game in 3 steps:

1. Install the SDK

Copy Assets/Scripts/SteamDLCProtectionClient.cs and DlcLoaderExample.cs into your Unity project.

Requires: Steamworks.NET + BouncyCastle.Crypto

2. Configure the Component

Attach SteamDLCProtectionClient to a GameObject in your scene.

Verify Endpoint: https://your-project.supabase.co/functions/v1/verify-dlc
API Key:         your-api-key-here
Steam App ID:    Your game's App ID (e.g. 480)
Target DLC ID:   The Steam DLC App ID
Offline Cache:   ✅ Enabled (24h default)

3. Encrypt Your DLC Bundle

# Generate an AES-256 key and encrypt your AssetBundle:
node tools/generate-aes-key.mjs
node tools/encrypt-dlc-bundle.mjs \
    path/to/your.bundle \
    path/to/your.enc \
    --key-base64 "YOUR_AES_KEY"

# Add the key to the DLC Protect dashboard
# The encrypted .enc file ships with your game

4. Load the DLC (C# Code)

public class MyGameLoader : MonoBehaviour {
    public SteamDLCProtectionClient protection;
    public TextAsset encryptedDlcFile;

    void Start() {
        protection.RequestDlcAccess(
            aesKey => {
                byte[] bundle = protection.DecryptDlcAssetBundle(
                    encryptedDlcFile.bytes, aesKey);
                AssetBundle.LoadFromMemory(bundle);
                Debug.Log("DLC Loaded! 🎉");
            },
            error => Debug.LogError("DLC failed: " + error)
        );
    }
}

✅ Offline Support Built In

Players authenticate once (online). A token is cached locally. For the next 24 hours (configurable), the DLC works even without internet. After expiry, the player needs to go online briefly to refresh.

API Key

Include this key in the X-Api-Key header of all requests.

API Endpoints
POST /verify-dlcVerify Steam ticket + DLC ownership, get wrapped AES key
POST /verify-offline-tokenUse cached offline token to get a new wrapped key
GET /healthHealth check
