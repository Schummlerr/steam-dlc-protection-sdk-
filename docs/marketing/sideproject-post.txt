# r/SideProject Post (zum Kopieren)

## Titel
I built an open-source tool that encrypts Steam DLCs with ECDH key exchange

## Text
Been working on this for a few weeks and it's finally in a usable state.

It's a Unity SDK + backend that adds runtime encryption to Steam DLCs. Instead of shipping DLC files in plaintext (where anyone can grab them), the game requests a decryption key from a server at runtime.

The crypto flow is:
• Ephemeral P-256 ECDH key pair per session (forward secrecy)
• Steam ticket validated via Valve's API
• Key delivered encrypted with ECDH-derived key
• AES-256-CBC+HMAC for the actual DLC encryption
• 24h offline JWT tokens so it works without internet

The Unity side is about 50 lines of C# with Steamworks.NET.

Full source: [github.com/Schummlerr/steam-dlc-protection-sdk-](https://github.com/Schummlerr/steam-dlc-protection-sdk-)

Would love feedback from other devs who've dealt with this problem!
