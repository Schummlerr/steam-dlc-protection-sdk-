How It Works

🔑 Key Exchange

Client generates an ephemeral P-256 ECDH key pair per session. The server agrees on a shared secret — no private key is ever transmitted.

✅ Steam Auth

Validates the player's Steam ticket via Valve's official API. Checks DLC ownership before delivering the decryption key.

🔒 AES-256 Delivery

The DLC's AES key is wrapped with the ECDH-derived transport key, signed with HMAC-SHA256, and delivered to the client.

📡 Offline Tokens

Players authenticate once and receive a 24-hour JWT token. The DLC works offline until the token expires.

Tech Stack

Backend

Supabase Edge Functions (Deno) with PostgreSQL. Multi-tenant SaaS architecture with rate limiting and API key auth.

Client

Unity 2022+ C# SDK with Steamworks.NET. 3 lines of code to load a protected DLC AssetBundle.

Crypto

ECDH P-256, AES-256-CBC+HMAC, HMAC-SHA256. Forward secrecy. Timing-safe comparisons. 31 passing tests.
