Integrate in 5 Minutes

1
Install the SDK

Copy SteamDLCProtectionClient.cs + DlcLoaderExample.cs into your Unity project. Requires Steamworks.NET + BouncyCastle.

2
Configure

Attach the component, set your endpoint + API key + Steam App ID + DLC ID.

3
Encrypt your bundle
node tools/generate-aes-key.mjs
node tools/encrypt-dlc-bundle.mjs game.bundle game.enc --key-base64 "YOUR_KEY"
4
Load in Unity
protection.RequestDlcAccess(aesKey => {
  var bundle = protection.DecryptDlcAssetBundle(encrypted.bytes, aesKey);
  AssetBundle.LoadFromMemory(bundle);
});
5
Done 🎉

Your DLC is now protected. Players authenticate via Steam once every 24h.

FAQ

Does the player need to be online? ▼
Once every 24 hours (configurable). Between authentications, an offline token cached on the device allows DLC access without internet.
Can the AES key be extracted? ▼
The key is never stored on disk. It's delivered per-session via ECDH key exchange (forward secrecy). Even if a session is intercepted, the key can't be reused.
What if the player doesn't own the DLC? ▼
The server checks ownership via Steam's official API. Unauthorized requests return 403.
Can I try before paying? ▼
Yes. Run the local test server (MOCK_STEAM=true) to test the full flow without a credit card or real Steam API key.
What if DLC Protect goes down? ▼
Cached offline tokens continue to work. Players who authenticated within the TTL window are unaffected by temporary outages.
